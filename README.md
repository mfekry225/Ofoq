# أُفق (Ofoq)

منصة لأخصائي التخاطب والتربية الخاصة: توثيق الجلسات والحضور والخطط الفردية، وبوابة لكل ولي أمر يرى ملف طفله فقط.

## التشغيل محلياً
```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

## إعداد Firebase (مرة واحدة)
1. **Authentication ← Sign-in method:** فعّل **Email/Password** فقط، وعطّل أي طريقة أخرى (Google, Anonymous).
2. **Authentication ← Users ← Add user:** أنشئ حسابك (بريدك + كلمة مرور قوية) وانسخ **UID**. احذف أي مستخدم لا تعرفه.
3. **Firestore Database:** اختر قاعدة البيانات المستخدمة في `firebase-config.json` (وليس `(default)`)، وأنشئ مجموعة `admins` ثم مستنداً **معرّفه = UID حسابك** وبه أي حقل (مثل `role: "owner"`). هذا ما يجعلك أخصائياً.
4. **Firestore ← Rules:** الصق محتوى `firestore.rules` على نفس القاعدة ثم **Publish**. أو بالأوامر: `firebase deploy --only firestore:rules`.

## حسابات أولياء الأمور
من ملف الطالب اضغط **إنشاء حساب**: اسم مستخدم + كلمة مرور (تُولَّد تلقائياً أو تكتبها). تظهر كلمة المرور **مرة واحدة** لنسخها أو إرسالها بالواتساب، ولا تُحفظ في أي مكان.
- نسي كلمة المرور؟ اضغط **إدارة الحساب ← إصدار بيانات جديدة** (باسم مستخدم جديد، ويُلغى القديم تلقائياً).
- لقطع الوصول فوراً: **إلغاء وصول ولي الأمر**.

## نموذج الأمان
- الأخصائي (مستند في `admins`): قراءة وكتابة كل شيء.
- ولي الأمر (مستند في `parents` يربطه بطفل واحد): قراءة ملف طفله وجلساته وتقييماته فقط، وإضافة نتيجة تقييم لطفله. لا يعدّل ولا يحذف شيئاً.
- الزائر: يقرأ الملف العام للأخصائي ويرسل طلب تسجيل فقط.
- أي مسار غير مذكور في القواعد مرفوض.

## اختبار القواعد (Rules Playground في Console)
- بدون تسجيل دخول: `get /students/أي-معرف` ← **مرفوض**. `create /leads/test1` بحقول صحيحة وstatus=`new` ← **مسموح**.
- بحساب ولي أمر: `get` لطالبه ← **مسموح**، ولطالب آخر ← **مرفوض**، و`update` لأي مستند ← **مرفوض**.
- بحساب الأخصائي: كل شيء **مسموح**.
